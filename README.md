# 大肥鱼

> 在 B 站养一条 AI 鱼：DSH 当大脑，哨兵按时叫醒，替你刷视频、回评论、看私信。

一条被养在 B 站账号里的鱼。它不常醒着——有个哨兵在旁边看着，到了该干活的时候才把大脑叫起来。醒着的时候，它会自己刷视频、挑喜欢的在评论区 @ 你，也会回你的评论和私信。

---

## 它是什么

四个部分：

| 部分 | 是什么 |
|---|---|
| **大脑** | DeepSeek Harness（DSH）的 agent，负责所有判断：回不回、刷什么、说什么 |
| **哨兵** | `code/fish.py`，一个不带智能的小程序。它只决定"该不该叫醒、什么时候叫醒"，不替 AI 做决定 |
| **手** | `code/tools.py`，14 个 B 站工具：看视频、搜视频、发评论、回评论、发私信、读私信…… |
| **控制台** | `code/panel.py`，本地网页，看状态、改配置、手动叫醒 |

## 它能做什么

- **到点刷视频**：每天按设定的时间刷 N 个没看过的视频，看完挑有感觉的在评论区 @ 主人
- **被 @ 就去看**：主人 @ 它一条视频，它去看、去回
- **回评论 / 回 @**：评论区有人找它，按它的判断接
- **看私信**：私信默认先过滤，无用的不叫醒
- **写日记**：每天把发生过的事整理一遍，存进 `memory/`
- **网页控制台**：不用命令行，点点鼠标就能看状态、改配置

## 为什么它不一直醒着

大模型一直在线很烧 token。所以这项目把"看"和"想"拆开了：

- 哨兵每 30 秒看一眼有没有新东西（很便宜）
- 只有满足条件（到点 / 够数量 / 有额度 / 主人叫）才叫醒 DSH
- AI 干完活就睡，下次醒来接着同一个会话

会话会一直续着，直到上下文太长才归档重开。

## 快速开始

**需要：** Windows、Python 3.10+、装好的 DeepSeek Harness、一个 B 站账号（建议小号）、一个 DeepSeek API key。

1. 双击 **`安装依赖.cmd`** —— 建 `.venv`，装依赖（默认走清华镜像，国内下载快）
2. 双击 **`首次运行.cmd`** —— 手机 B 站扫码登录，填 DeepSeek key，自动探测本机 `dsh`
3. 双击 **`启动哨兵.cmd`** —— 开始值班

想先看它刷一轮视频，就双击 **`启动哨兵-先刷视频.cmd`**。
想看状态 / 改设置，双击 **`控制台.cmd`**，浏览器打开 `http://127.0.0.1:8765`。

> 依赖默认从清华镜像下载。如果镜像不可用，打开 `安装依赖.cmd`，把开头的 `set "PIP_INDEX=..."` 改成 `https://pypi.org/simple` 再跑一次。

```
dafeiyu/
├─ code/
│  ├─ fish.py           哨兵：定时看、按闸叫醒
│  ├─ tools.py          AI 的 14 个 B 站工具（MCP）
│  ├─ panel.py          网页控制台
│  └─ setup_wizard.py   第一次运行向导
├─ IDENTITY.md          它是谁（人格）
├─ DUTY.md              它该干什么（职责）
├─ TOOLS.md             工具说明书
├─ config.example.json  配置模板（首次运行会生成 config.json）
├─ requirements.txt

├─ 首次运行.cmd
├─ 启动哨兵.cmd
├─ 启动哨兵-先刷视频.cmd
```

运行后还会生成（已在 `.gitignore` 里，不会进仓库）：

```

config.json   你的配置（含 API key）
memory/       它的记忆：流水、日记、长期记忆
logs/         哨兵日志
inbox/        给 AI 的任务包
dsh-home/     DSH 的独立运行目录
```

## 配置

`config.json` 里常改的几项：

| 键 | 默认 | 说明 |
|---|---|---|
| `wake_interval_seconds` | 90 | 哨兵多久看一次（秒） |
| `min_count` | 1 | 攒够几条消息才叫醒 |
| `caps.scan_per_day` | 15 | 每天刷几个视频 |
| `caps.daily_people` | 5 | 每天最多跟几个人互动 |
| `caps.per_video` | 5 | 每个视频最多发几条 |
| `caps.per_thread` | 3 | 每个楼层最多几条 |
| `caps.hard` | false | `true` = 额度硬拦（代码拒绝），`false` = 软提醒 |
| `scan_at` | 12:30 / 21:00 | 每天刷视频的时间点 |
| `diary_at` | 21:30 | 写日记的时间 |
| `mode` | 2 | 提醒/自动档位，见 `DUTY.md` |
| `attitude` | yes / yes / filter | @ / 回复 / 私信 的态度 |

改完不用重启，哨兵下一轮（约 30 秒内）就会读到。

## 常见问题

**找不到 dsh？**
先装 DeepSeek Harness，确认命令行里 `dsh --version` 能跑。或者把 `dsh` 的完整路径填进 `config.json` 的 `dsh_bin`。

**扫码后没反应？**
二维码过期了，重新跑一次 `首次运行.cmd` 就行。

**凭据失效？**
重新跑 `首次运行.cmd` 扫码，会覆盖旧的。

**它不回评论 / 不刷视频？**
先看 `logs/sentinel-日期.log`。常见原因：`sentinel_enabled` 关了、额度用完了、`attitude` 设成了 `forbid`、DSH 叫醒失败。

**会不会被封号？**
会。这是把账号交给 AI 的项目，评论、私信、刷视频都是真实操作。B 站有风控，账号有可能被限流或封禁。**用你自己的小号，风险自己承担。**

## 注意

- `config.json` 和 `credential/` 里有你的 key 和登录凭据，**不要发给别人，不要上传**。
- 项目默认所有配置在本地，不上传任何数据。
- 只对 B 站做了适配，别的平台没有。
