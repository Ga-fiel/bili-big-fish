# 日记和记忆

写日记、读日记、记长期的事。这三个不碰 B站。

---

### `read_diary`
| 参数 | 说明 |
|---|---|
| `date` | `YYYY-MM-DD`，留空=今天 |

### `write_diary`
| 参数 | 说明 |
|---|---|
| `md` | 整篇日记的完整内容 |
| `date` | 留空=今天 |

**这是整篇覆盖，不是追加。** 同一天写第二次，必须先把已有的读出来、拼上新内容、再整体写回。

### `remember`
| 参数 | 说明 |
|---|---|
| `text` | 一句话 |

追加到 `memory/longterm.md`。适合记"主人提过他讨厌标题党"这种长期有效的事。

---

## 常见活儿

**写今天的日记**
```
read_diary()                  ← 先读今天的，看看已经写了什么
write_diary(整篇新内容)       ← 整篇写回（不是追加！）
remember("一句长期有用的话")  ← 顺手记一条
```
