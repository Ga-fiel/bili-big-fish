# 看视频和找视频

看一个视频：读信息、字幕、AI 总结、弹幕、相关推荐、记看法。
找视频：搜索、首页、热门、分区、排行榜、热搜。

---

## 看视频

### `read_video`
| 参数 | 说明 |
|---|---|
| `bvid` | 例如 `BV16KnN6KEwo` |
| `oid` | 视频 aid，二选一 |

返回一段文本，头两行是 `oid：…` 和 `bvid：…`（拿 `oid` 就能直接 `comment_video` 或 `post_reply`），
然后标题 / UP / 时长 / 分区 / 播放 / 简介（前 300 字）/ 3 条热门评论。
要字幕用 `read_subtitle`（前 N 字）或 `read_subtitle_all`（全文）；要 AI 总结用 `read_video_ai`。

**调一次它就记一次账**：这个视频会写进 `seen_videos.json`，`search_videos` 以后不再给你。
所以"读过的视频"不用你自己记，系统替你记了。

### `read_subtitle`
读视频字幕的前 N 个字。

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` | 二选一 | 视频 BV 号 |
| `oid` | 二选一 | 视频 aid |
| `chars` | 否 | 最多读几个字，默认 500 |

返回字幕文本。太长会截断，并在末尾写「（共 N 字，要更多就加大 chars，或者用 read_subtitle_all）」。
没有字幕会报错。

### `read_subtitle_all`
读视频的全部字幕（最多 10000 字）。参数和 `read_subtitle` 一样，没有 `chars`。

### `read_video_ai`
读视频的 AI 总结：一段总结 + 几个小标题（每个小标题一行，前面是 `·`）。
参数 `bvid` 或 `oid`。没有 AI 总结会报错。

### `list_danmakus`
读视频的弹幕。

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` / `oid` | 二选一 | 视频 |
| `limit` | 否 | 最多显示几条，默认 50 |

返回 `[mm:ss] 内容` 一行一条，末尾写共多少条。

### `send_danmaku`
发一条弹幕。

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` / `oid` | 二选一 | 视频 |
| `text` | 是 | 弹幕内容，≤ 100 字 |
| `progress` | 否 | 出现在视频第几毫秒，默认 0 |
| `mode` | 否 | 1 滚动（默认）/ 4 底部 / 5 顶部 |

返回 `{"sent": true, "text", "progress_ms", "mode", "raw": {…}}`。

### `list_related`
一个视频的相关推荐。参数 `bvid` / `oid`、`limit`（默认 10）。
返回 `bvid | 标题 | UP | 播放` 一行一条。

### `watch_video`
给看过的视频补一句"你的看法"。**不是必填**，但很有用：以后再碰到同一个 UP 或者同类视频，
你自己翻记录时能想起来"上次那种我不太吃"。

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` | 是 | |
| `verdict` | 否 | `like` / `meh` / `skip` |
| `note` | 否 | 一句话，≤ 300 字 |

返回 `{"ok": true, "watched": "BV…", "verdict": "…", "total": 42}`。

> `read_video` 已经自动记账了，`watch_video` 不会重复计数，只是补上 `verdict` 和 `note`。

## 找视频

### `search_videos`
| 参数 | 默认 | 说明 |
|---|---|---|
| `keyword` | — | 必填 |
| `order` | `"pubdate"` | `pubdate` 最新 / `click` 最热 |
| `min_play` | 0 | 最低播放量 |
| `days` | 7 | 只保留几天内发的，`0` 表示不限 |
| — | — | 返回最多 30 条，**每行一个 JSON** |

**它已经自动跳过你读过的视频**（记在 `seen_videos.json` 里），不用你自己查重。

**关键词是你自己想的。** 主人不再给方向，你每次搜之前先给自己定几个词 —— 想看的、好奇的、最近在聊的。
看腻了就换词，别用同一组搜一礼拜。

每条字段：`bvid` `title` `up` `play` `duration`（如 `"19:28"`）`pubdate` `desc`。

`order="pubdate"` 是刚发的，播放量普遍很低；`order="click"` 是热门的，但会飘出几个月前的老视频。
两个都搜一遍，混着挑，比只搜一个强。

### `homepage_videos`
首页推荐视频。`limit` 默认 10。返回 `bvid | 标题 | UP`。

### `hot_videos`
热门视频。

| 参数 | 必填 | 说明 |
|---|---|---|
| `kind` | 否 | `hot` 热门（默认）/ `weekly` 每周必看 |
| `limit` | 否 | 默认 10 |

### `zone_videos`
分区排行。

| 参数 | 必填 | 说明 |
|---|---|---|
| `tid` | 是 | 分区 id |
| `kind` | 否 | 目前只能 `top10`；`new` 会直接报「分区最新投稿接口 B站 已经关了」 |

返回 `bvid | 标题 | UP | 播放`。

### `rank_videos`
全站排行榜。`limit` 默认 10。返回 `bvid | 标题 | UP`。

### `hot_search`
B站热搜词，无参数。返回 `关键词（展示名）` 一行一条。

## 常见活儿

**刷视频**
```
peek_inbox → 自己想几个词 → search_videos(keyword, "pubdate")
                              search_videos(keyword, "click")
           → read_video(bvid)  ← 看，同时自动记账
           → 三种后续，自己选：
              什么都不做
              comment_video(text, oid)      ← 有自己的话想说（会自动 @ 主人）
              send_dm(123456789, text)     ← 值得给主人看
```
`daily_new` 是几个就刷几个，每个都 `read_video` 过一遍才算数。

**找点新东西看**
```
homepage_videos()          ← 首页推荐
hot_videos("hot")          ← 热门
hot_videos("weekly")       ← 每周必看
zone_videos(tid)           ← 某个分区排行
rank_videos()              ← 全站排行
hot_search()               ← 今天大家在搜什么
```

**读字幕、AI 总结**
```
read_subtitle(bvid)                ← 前 500 字
read_subtitle(bvid, chars=2000)    ← 前 2000 字
read_subtitle_all(bvid)            ← 全部字幕
read_video_ai(bvid)                ← AI 总结
```

**发弹幕 / 读弹幕**
```
list_danmakus(bvid)                       ← 看弹幕
send_danmaku(bvid, "……", progress=3000)   ← 发一条，progress 是第几毫秒
```
