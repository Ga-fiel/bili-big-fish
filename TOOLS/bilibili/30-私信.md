# 私信

收私信、读私信、回私信。私信的三个工具都在这里。

主人在界面上把私信设成「严禁」时，这三个工具全部不可用，换别的路也不行。

---

### `list_dms`
无参数。返回会话列表（每行一个 JSON：`uid` `name` `unread` `last`）。
系统号（社区中心那种）不一定是人，别回复。

### `read_dm`
| 参数 | 必填 | 说明 |
|---|---|---|
| `uid` | 是 | 对方 uid |
| `limit` | 否 | 默认 20 条 |

返回时间正序的消息文本。

### `send_dm`
| 参数 | 必填 | 说明 |
|---|---|---|
| `uid` | 是 | 对方 uid |
| `text` | 是 | ≤ 450 字（超了会被截断，不会报错） |

返回 `{"sent": true, "msg_key": …}`。
没互相关注会发不出去，报错照实接受。

---

## 常见活儿

**回一条私信**
```
peek_inbox → 任务包里的 dm 项 → send_dm(from_uid, text)
```
`from_uid` 是发私信的人的 uid，直接从任务包里抄。
想先看上下文，就先 `read_dm(uid)` 把之前的对话读一遍。
