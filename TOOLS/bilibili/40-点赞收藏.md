# 点赞收藏

视频的点赞、投币、收藏、收藏夹管理、稍后再看。

---

### `like_video`
给视频点赞 / 取消点赞。

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` | 二选一 | 例如 `BV16KnN6KEwo` |
| `oid` | 二选一 | 视频 aid |
| `undo` | 否 | `true` = 取消点赞，默认 `false` |

返回 `{"liked": true/false, "bvid": …, "res": …}`。

### `coin_video`
给视频投币。**硬币是真钱，投出去不回来。**

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` / `oid` | 二选一 | 同 `like_video` |
| `num` | 否 | 1 或 2 枚，默认 1 |
| `also_like` | 否 | 投币同时点赞，默认 `false` |

返回 `{"coins": 1, "also_like": false, "res": …}`。硬币不够或已经投过会报错。

### `list_fav_folders`
无参数。列出自己的收藏夹，每项 `media_id` `title` `count` `privacy`。
`folder_id` 就是这里的 `media_id`。

### `list_fav_medias`
| 参数 | 必填 | 说明 |
|---|---|---|
| `media_id` | 是 | 收藏夹 id（从 `list_fav_folders` 拿） |
| `page` | 否 | 第几页，默认 1 |

返回每项 `bvid` `title` `up` `fav_time`。

### `create_fav_folder`
新建一个收藏夹。

| 参数 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 收藏夹名字 |
| `privacy` | 否 | `0` 公开 / `1` 私密，默认 `0` |

返回 `{"media_id": 新收藏夹 id, "title": …}`。

### `delete_fav_folder`
删掉一个收藏夹，**里面的收藏会一起没**。

| 参数 | 必填 | 说明 |
|---|---|---|
| `media_id` | 是 | 收藏夹 id |

返回 `{"deleted_media_id": …}`。

### `favorite_video`
把视频收藏进收藏夹，或从收藏夹移出。

| 参数 | 必填 | 说明 |
|---|---|---|
| `bvid` / `oid` | 二选一 | 视频 |
| `folder_id` | 是 | 收藏夹 id |
| `undo` | 否 | `true` = 从收藏夹移出，默认 `false` |

返回 `{"added": true/false, "folder_id": …}`。

### `add_to_toview`
把视频加进稍后再看；`undo: true` 就从稍后再看里移出来。
参数 `bvid` / `oid`、`undo`。

### `list_toview`
列稍后再看。`limit` 默认 20。返回 `bvid | 标题 | aid`。
（刚加进去的可能要过几分钟才在列表里出现。）

---

## 常见活儿

**看到喜欢的视频**
```
like_video(bvid)                 ← 点赞
coin_video(bvid)                 ← 投币（硬币真钱，想清楚）
favorite_video(bvid, folder_id)  ← 收藏
```

**先存着以后看**
```
add_to_toview(bvid)    ← 塞进稍后再看
list_toview()          ← 回头翻
add_to_toview(bvid, undo=True)   ← 看完了 / 不想看了
```

**整理收藏夹**
```
list_fav_folders()                          ← 先看有哪些夹子
create_fav_folder("以后要看的", privacy=1)   ← 新建一个私密夹
list_fav_medias(media_id)                   ← 看夹子里有什么
delete_fav_folder(media_id)                 ← 删夹子（里面的收藏一起没）
```
