# 人和数据

看一个人的主页、把名字转成 uid、看自己账号的数据、看 UP 主数据、搜视频以外的东西。

---

### `view_user`
看一个人的主页：昵称、签名、等级、粉丝数，加上他最新发的视频。

| 参数 | 必填 | 说明 |
|---|---|---|
| `uid` | 是 | 对方 uid |
| `limit` | 否 | 取几个视频，默认 20，最多 30 |

返回 `{"uid", "name", "sign", "level", "fans", "videos": [{bvid, title, play, created}]}`。

### `name_to_uid`
B站用户名转 uid。参数 `name`。
返回 `uid | 昵称` 一行一个；重名会列好几个。

### `self_info`
看自己账号的数据，无参数。
返回 `{uid, name, level, coins, fans, following, sign}`。

### `up_stat`
看一个 UP 主的数据。

| 参数 | 必填 | 说明 |
|---|---|---|
| `uid` | 是 | UP 主 uid |

返回 `{uid, fans, play, likes, videos, articles}`。

### `search_other`
搜视频以外的东西。

| 参数 | 必填 | 说明 |
|---|---|---|
| `keyword` | 是 | 关键词 |
| `type` | 否 | `user`（默认）/ `article` / `bangumi` / `live` / `topic` |

返回按类型不同：用户是 `uid | 昵称 | 粉丝`，专栏是 `id | 标题 | UP`，直播是 `房间号 | 标题 | UP`。
话题接口经常被 B站 降级，会直接报「这次搜不了」。

---

## 常见活儿

**看一个人**
```
name_to_uid("某某")   ← 先拿到 uid
view_user(uid)        ← 主页：签名、等级、粉丝、最近视频
up_stat(uid)          ← 数据：粉丝、播放、点赞、投稿数
```

**看自己**
```
self_info()   ← 自己账号的 uid/昵称/等级/硬币/粉丝/关注
```

**搜人 / 搜专栏 / 搜直播**
```
search_other("关键词", "user")      ← 找人
search_other("关键词", "article")   ← 找专栏
search_other("关键词", "live")      ← 找直播间
```
