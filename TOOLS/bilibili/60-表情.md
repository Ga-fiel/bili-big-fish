# 表情

发本地表情、查官方表情包。

本地的表情放在 `表情库/` 文件夹里，文件名就是它的意思。比如 `偷笑（嘻嘻）.jpg` 的意思就是"偷笑"、"嘻嘻"。

---

### `list_stickers`
列出本地表情库里的表情。文件名就是它的意思。

| 参数 | 必填 | 说明 |
|---|---|---|
| `keyword` | 否 | 只列名字里带这个词的 |

返回一行一个名字，不带后缀。比如 `偷笑`、`笑`、`搓自己（可爱）`。

### `send_sticker`
发一张本地表情。`target` 决定发到哪儿。

| 参数 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 表情名字，`list_stickers` 里看到的那个 |
| `target` | 否 | `comment`（默认）/ `dm` / `dynamic` |
| `oid` | 评论视频时 | 视频的 aid |
| `dyn_id` | 评论动态时 | 动态的 id，`/opus/` 后面那串数字 |
| `rpid` | 否 | 回复某条评论时给 |
| `root` | 否 | 楼层根 |
| `uid` | 私信时 | 收私信的人的 uid |
| `text` | 评论时 | 配的文字，评论必填；动态可省 |

- 评论发图必须带一句话，纯图的评论发不出去。
- 动态可以只发图，`text` 不给也行。
- 图会自动上传到 B站，返回里 `sticker` 是文件名；评论给 `rpid`，动态给 `url`。
- 动图（gif）在评论区可能发不出去（账号没有评论动图权限），报 49044 就是那个原因。

### `list_emoji`
列官方表情包。

| 参数 | 必填 | 说明 |
|---|---|---|
| `package_id` | 否 | 不给：列所有包，`id | 名称`；给了：列这个包里的表情文本 |

返回包列表或表情文本（比如 `[偷笑]`）。

---

## 常见活儿

**发个表情**
```
list_stickers()                              ← 先看有什么
send_sticker("偷笑", oid=…, text="……")       ← 评论带图，文字必填
send_sticker("偷笑", target="dm", uid=…)     ← 私信发图
send_sticker("偷笑", target="dynamic", text="……")   ← 动态带图
```

**查官方表情**
```
list_emoji()          ← 所有包
list_emoji(123)       ← 某个包里的表情
```
